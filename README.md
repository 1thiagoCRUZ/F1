🔗 **Acesse o projeto online:** 👉 [Clique aqui para ver como está por enquanto](https://1thiagocruz.github.io/F1/)
 
🎨 **Acesse o Figma do projeto:** 👉 [Layout Figma](https://www.figma.com/design/bevMGEEETyIAP39cdQrsr7/FormulaOne?node-id=257-222&t=DpPtN5aUIeur4Oxa-1)

## 📋 Sobre

Criei esse projeto para brincar com animações e layout, recriando a sequência de luzes da largada e uma galeria visual das equipes atuais da fórmula 1.


**🚧 Status:** Em construção.
*Atualmente as equipes: Alpine, Aston Martin, Ferrari, McLaren e Mercedes estão com suas galerias configuradas. As outras serão adicionadas em breve.*

## 🤝 Contribuição

Como ainda faltam várias equipes, sinta-se à vontade para abrir um **Pull Request** e ajudar a terminar o grid!

1. Faça um Fork do projeto.
2. Configure uma nova equipe (ex: Red Bull, Haas).
3. Mande seu PR.
